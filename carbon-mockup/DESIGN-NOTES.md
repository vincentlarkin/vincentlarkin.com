## Content provenance and scope

Photographs and dates come from the original `js/site.js`; profile content comes from `about.html`; reading links come from `news.html`; commits come from the local Git history. Public project descriptions follow the original homepage. Layout and decorative illustrations are mockup design choices. Following review, the introductory slogans were removed in favor of factual labels, the header was increased to 56px, and the portrait was reduced to 160px on desktop and 128px on mobile.

The bookshelf remains empty because the source has no books. The production changelog requests live GitHub commits and labels its saved fallback when GitHub is unavailable. The production privacy page retains the website's actual policy, updated to describe theme measurement. Project and status links keep their existing destinations.

No brand-new stock photography, fabricated projects, invented metrics, or testimonials were introduced.

## Keyboard refinement

The photo and search overlays enable Carbon’s documented `enableFocusWrapWithoutSentinels` option, supply explicit launcher references for focus restoration, and share a capture-phase Escape handler. This ensures the dialog closes even when a nested icon tooltip consumes Escape. The behavior is verified by cycling Tab through the dialog and checking focus on its original trigger after dismissal. See [Modal implementation guidance](https://carbondesignsystem.com/components/modal/code/).
